# Contributing to GR00T-VisualSim2Real

We welcome external contributions!

## Developer Certificate of Origin (DCO)
To comply with NVIDIA's open-source policy, all contributions must follow the Developer Certificate of Origin (DCO) process.

All pull requests must include a "Signed-off-by" line in the commit message to certify that you have the right to submit the code under the Apache 2.0 license.

For the full DCO language and process, please refer to:
https://github.com/NVIDIA/GEAR/blob/main/CONTRIBUTING
