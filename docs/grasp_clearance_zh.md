# 统一抓取间隙

外部抓取和背筐抓取统一使用`gr00t/rl/pick/grasp_clearance.py`中的`GRASP_CLEARANCE_M = 0.006`，不再分别默认2 mm与6 mm。准入、在线抓取规划、站位筛选、诊断探针使用同一值；背筐不再在准入入口额外抬高该阈值。抓取方向、凹槽中心深度及机身/机械臂其他验收未改。

变体缓存键包含该公共阈值，避免复用旧标准的缓存。显式非默认间隙仅可用于诊断，不能发布默认准入库。
