# 静动摩擦减半后的推拉门 Debug 复验

## 实验配置

共用 `run_auto_open.sh` 的正式debug入口，推门、拉门各1700–1703，四卡、六视角、完整穿门。六个机械臂关节与夹爪的静/动库仑摩擦均为参考值的0.5，黏性摩擦、PD增益和重力补偿不变。运行期间关闭trunk滤波，结束后恢复工作区此前的True覆盖。

包含此前已完成的局部修复：张开恢复闭合前保存的实际世界系高度，轨迹完成及3 mm高度误差连续10帧验收；40 cm无解时选前进射线最近点、使用已有到位停止；末尾保持先确认收臂完成再累计。实验期间不改控制或验收。

## 已结束失败的定位

推门1701收臂末尾50帧，底盘发布全零，机身位置变化小于0.17 mm，没有非足部外接触。q3/q4实际每帧在两组角度之间交替，峰峰值5.72°/15.03°，对应关节目标峰峰值5.92°/13.55°。这是动态振荡，不能解释为静摩擦导致的静态到位残差。收臂开头7帧曾与门板接触、峰值140.72 N，但末段持续振荡时接触早已消失。

复算低层当前姿态增益4、同一实测姿态和当前DLS公式，关节目标与日志最大仅差0.026°。在固定底盘、理想关节跟随的纯数学反事实中，初始4.22°误差，增益4首次纠正后越过目标仍为4.13°，第二步4.05°；增益1则为2.13°、1.08°。因此当前增益带来近乎翻转误差的纠正，在真实动力学下没有收敛。理想跟随的增益4在40步后仍逐渐降至2.00°，不能把它说成纯IK本身永不收敛，也不能仅凭本轮断言摩擦减半是唯一诱因。没有修改生产增益或验收阈值。

证据：`artifacts/lab30_dynamics/push1701_half_friction_stow_analysis.json`。注意日志中EE刚体姿态在该窗口与上一帧关节FK匹配，不能把同一行的FK与EE差直接全算成机械形变；上面的振荡结论来自实际关节、发布关节目标和独立低层公式复算。
